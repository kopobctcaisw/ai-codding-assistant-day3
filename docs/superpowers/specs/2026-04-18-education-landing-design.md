# 교육/학습 서비스 프리미엄 랜딩페이지 설계서

## 1. 목표
개인 소비자(B2C)를 대상으로 한 교육/학습 서비스 랜딩사이트를 구축한다. 핵심 전환 목표는 상담/문의 신청이며, 전환 채널은 카카오톡 채널로 통일한다.

## 2. 범위
- 포함
  - 3개 정적 페이지 구현
    - `/` 메인
    - `/programs` 프로그램
    - `/consulting` 상담안내
  - 프리미엄·고급형 브랜드 톤의 UI 시스템
  - 공통 CTA를 카카오톡 채널로 연결
  - 반응형 레이아웃(모바일 우선)
- 제외
  - 백엔드 API 연동
  - 회원 기능
  - 결제 기능
  - CMS 도입

## 3. 기술 아키텍처
- 프레임워크: React + Vite
- 라우팅: React Router
- 배포: 정적 호스팅(Netlify/Vercel/GitHub Pages 중 택1)
- 데이터: 정적 콘텐츠 파일(`src/content/*.ts`) 기반 렌더링

### 3.1 라우트 구조
- `/`: 서비스 가치 전달 및 1차 전환 유도
- `/programs`: 프로그램 상세·학습 프로세스 제공
- `/consulting`: 상담 절차·대상·시간 안내 및 최종 전환 유도

## 4. UI/컴포넌트 설계
### 4.1 공통 컴포넌트
- `Header`: 주요 네비게이션 및 상단 CTA
- `Footer`: 신뢰 요소 및 하단 링크
- `PrimaryCTAButton`: 카카오톡 채널 연결용 공통 버튼
- `SectionTitle`: 섹션 제목 스타일 통일
- `TestimonialCard`: 후기/성과 카드

### 4.2 페이지별 섹션
- 메인(`/`)
  - Hero
  - 개인 맞춤 커리큘럼 가치 제안
  - 성과/후기 섹션
  - 중간·하단 CTA 배너
- 프로그램(`/programs`)
  - 프로그램 카드(예: 입문/심화)
  - 학습 프로세스
  - FAQ
- 상담안내(`/consulting`)
  - 상담 대상
  - 상담 절차
  - 준비사항
  - 상담 가능 시간
  - 최종 CTA

## 5. 콘텐츠/데이터 구조
- 콘텐츠 분리 원칙: 화면 컴포넌트와 텍스트/카드 데이터 분리
- 저장 위치: `src/content/*.ts`
- 관리 항목
  - 공통 카피
  - 프로그램 리스트
  - 후기/성과 데이터
  - FAQ 목록
  - CTA 링크(카카오톡 채널 URL)

## 6. 전환(CTA) 정책
- 모든 핵심 CTA는 카카오톡 채널 링크로 통일
- 링크 오타/불일치 방지를 위해 URL 상수 단일 관리
- 클릭 시 새 탭 열기 적용

## 7. 디자인 가이드(기본안)
브랜드 자산이 없는 상태를 전제로 기본 가이드를 사용한다.

- 톤: 프리미엄·고급형
- 컬러
  - Primary: Deep Navy 계열
  - Accent: Gold 계열
  - Neutral: 밝은 배경 + 고대비 텍스트
- 타이포
  - 제목: 강한 대비의 굵은 스타일
  - 본문: 가독성 우선의 중간 굵기
- 레이아웃
  - 모바일 우선, 충분한 여백과 명확한 시각적 계층

## 8. 접근성/반응형
- 접근성
  - 버튼/링크 의미가 드러나는 라벨 사용
  - 키보드 포커스 표시 유지
  - 충분한 색상 대비 유지
- 반응형 브레이크포인트
  - 기본: 모바일
  - 768px: 태블릿
  - 1024px: 데스크톱

## 9. 테스트 및 완료 기준
- 스모크 테스트
  - 각 라우트 정상 진입
  - 각 페이지 CTA 노출 확인
  - CTA 링크 값이 카카오톡 채널 URL 상수와 일치
- 빌드 검증
  - `npm run build` 성공
- 완료 기준
  - 3개 페이지와 공통 컴포넌트가 설계대로 동작
  - 반응형 및 접근성 기본 요구 충족

## 10. 구현 원칙
- YAGNI 원칙 준수(현 요구사항 외 기능 추가 금지)
- 과도한 추상화 지양
- 유지보수 편의를 위해 콘텐츠와 UI 분리 우선
